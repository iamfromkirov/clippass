# PASS_COPY

Маленькое окно «всегда поверх всех» для Windows: выбираешь имя из списка — связанный с ним текст копируется в буфер обмена. Данные берутся из защищённого паролем Excel-файла data.xls.

Написано на C# (.NET 8, WinForms).

## Возможности

- Читает `data.xlsx` (в том числе зашифрованный паролем): колонка A — имя, колонка B — текст.
- Выбор имени копирует текст в буфер обмена; в заголовке окна на мгновенье появляется «✓ Скопировано».
- Пункт «⟳ Обновить» в конце списка перечитывает файл вручную.
- Автоматически перечитывает файл при его изменении (проверка раз в 30 минут).
- Окно удерживается поверх остальных (не мешает раскрытому списку).
- Файл можно читать, даже если он открыт в Excel.

## Запуск

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download) и Windows.

1. Скопируйте `config.example.json` в `config.json` и укажите пароль:
   ```json
   {
     "FilePath": "data.xlsx",
     "ExcelPassword": "your-password-here"
   }
   ```
   Пароль можно также передать переменной окружения `ESMA_PASSWORD` (она приоритетнее файла).
2. Положите `data.xlsx` рядом с `Esma.exe` (или укажите другой путь в `FilePath`).
3. Соберите и запустите:
   ```
   dotnet run -c Release
   ```

## Публикация одним exe

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Результат — в `bin/Release/net8.0-windows/win-x64/publish/`. `config.json` и `data.xlsx` положите рядом с exe.

## Настройки (`config.json`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `FilePath` | `data.xlsx` | Путь к Excel-файлу (относительный — от папки с exe) |
| `ExcelPassword` | пусто | Пароль к файлу |
| `FeedbackDurationMs` | `800` | Сколько показывать временный заголовок |
| `RefreshCheckIntervalMs` | `1800000` | Интервал проверки изменений файла |
| `TopmostEnforceIntervalMs` | `10000` | Интервал восстановления «поверх всех окон» |
